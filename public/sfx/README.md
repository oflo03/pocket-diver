# Sound effects

Short clips played by `src/sfx.js`, one file per sound (a missing file stays silent).
All are CC0 (public domain) from OpenGameArt.org; credit is not required but listed here.
Converted to mono 96 kbps MP3; `bolt`, `focus` and `net` are cut short with a fade.
