## 게임에 배치하기

생성 원본의 캔버스 크기와 내부 선체 높이에 차이가 있어, 중앙 정렬로 단순 교체하면 위치가 움직일 수 있습니다. `marine-base-stages.json`에 각 이미지의 실제 크기와 권장 수면 기준점을 기록했습니다. 모든 단계에 같은 배율을 적용하고 권장 기준점을 같은 월드 좌표에 맞추면 됩니다.

- 이미지 좌측 위 위치: `worldX - anchorX × scale`, `waterlineY - anchorY × scale`.
- `suggested_waterline_anchor_px`는 원본 픽셀 기준이며, 선체 바닥 약 32픽셀 위를 권장 수면으로 정했습니다.
- 실제 게임에서 원하는 잠김 깊이에 맞춰 수면 기준점을 조정할 수 있습니다. 물결은 별도 레이어를 앞에 그려 연결하세요.
- 좌표는 배치 가이드이며 충돌 영역이나 타일 단위 규격은 아닙니다.
- 도트 확대·축소 표시에는 nearest-neighbor 방식이 적합합니다. 원본 PNG에는 추가 리사이즈나 잘라내기를 하지 않았습니다.
